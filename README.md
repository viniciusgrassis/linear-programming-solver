# trabalho_po

Para inserção, o formato deve ser, com os valores 'c' sendo os coeficientes da função objetivo. 
Os valores 'a' são os coeficientes das restrições. 'r' indicam o tipo de restrição, sendo 0 do
tipo ≥ e 1 do tipo ≤. Os 'b' representam os coeficientes do lado direito. Exemplo:

c1 c2

a1 a2 
a3 a4
a5 a6

r1
r2
r3

b1
b2
b3
